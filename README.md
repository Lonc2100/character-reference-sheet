# 四格角色参考图

为已批准的成年角色制作固定2:3四格设定图提示词：上排正脸与45度肖像，下排无头正面与严格侧面身体。用于后续人物身份、服装和体型参考。

## 安装
`npx skills add Lonc2100/character-reference-sheet --skill character-reference-sheet`

或者复制整个目录到兼容 Agent Skills 的客户端。普通 ChatGPT 上传资料不等于安装 Skill。

## 使用
“使用 $character-reference-sheet，把这些批准角色图和文字设定做成四格参考图提示词，画风保持原设。”

输入：成年年龄、已批准角色资料、画风；可提供身份与画风参考图。输出：锁定表、完整英文提示词、未决字段；只有明确要求生图时才调用环境已有的图像工具。

模板来源为作者提供的原文，完整保存在 templates/character-sheet-prompt.txt。无额外CLI、API密钥或付费服务依赖；真正生图需要客户端提供图像能力。

## 限制与排错
未知年龄、画风或身份不猜填；参考冲突先处理。下排是无头身体裁切，并非通常的含头三视图。模型不能保证一次严格符合版式，需按验收表检查并局部修正。提示词与结构验证不能证明成图质量；当前没有实际生图或用户视觉验收证据。

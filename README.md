# 人物参考与刷光｜第四期配套Skill

已有角色在不同镜头里变脸，或看起来像贴在场景上？先检查参考输入：大小脸是否相互矛盾，人物受光是否和环境一致。这个Skill把已批准角色编译成四格参考图提示词，并按同一环境准备人物刷光与验证方案。

## 安装

```bash
npx skills add Lonc2100/character-reference-sheet --skill character-reference-sheet
```

将整个目录放入支持Agent Skills的客户端也可以。普通ChatGPT读取提示词不等于安装Skill；真正生图/生视频需要客户端已有的图像或视频工具。

## 你可以直接这样说

“使用 $character-reference-sheet，沿用这些批准的成年角色资料，做上排大脸、下排无头身体的四格参考图提示词。”

“使用 $character-reference-sheet，只按这张夜景环境给人物参考刷光，脸、衣服、画风、版式和白背景保持。”

“审核这两路实际视频：原面光人物＋同一环境，与刷光人物＋同一环境。只报告看得到的差异。”

## 输出与文件

角色锁定表、完整人物提示词、刷光提示词、共用视频测试提示词及验收清单。人物版式详见templates/character-sheet-prompt.txt；刷光不强制把单人图改成四格。

角色、图片和资料默认留在用户自己的项目目录。Skill不内置API密钥、运行时、付费服务，也不自动上传或发布。默认交提示词，用户明确要求且授权工具时才生成。

## 第四期更新

v1.1.0在原v1.0.0人物参考Skill上增加人物参考刷光、同环境视频验证和道具比例证据边界，修正接口文件的重复配置。保留原四格完整模板，不用“模型偷懒”替代已证明的内部机制。

## Troubleshooting

装好不触发：确认客户端发现根目录SKILL.md，再显式调用名称。人物被改脸：回看身份锁定，不继续叠滤镜。白背景被刷成场景：明确环境只提供受光。没有生成工具：照常输出提示词和待验项目，不冒充已生成。

项目实例提示词已用于第四期素材，但新角色、跨模型效果需要实际生成和视觉审核；静态结构与触发测试不证明每次身份或光照都稳定。本次发布不新增付费生成。无关人物照片、私人成片、账号资料与项目日志不入包。

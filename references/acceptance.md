# 成图验收

逐项标注通过、失败或无法判断，并指出具体格与可见依据。

- 画布2:3、2×2等宽，上排34–36%、下排64–66%，无文字、水印或景物。
- 左上正脸、完整头发、锁骨下紧裁、直立不歪头；右上45度头颈肩胸同向，脸大小相同，眼神不单独回看镜头。
- 两个上排身份、眼色、妆容、曝光和发长一致。
- 两个下排头脸完全不入框；颈根至鞋底占格高93–96%，手脚鞋无裁切。
- 左下正面中性站姿，右下严格90度侧面，全身关节同向，无三分之四角度。
- 下排肩、腰、胯、膝与地面线等高，身体尺度、鞋尺度一致，无拉腿缩头或改体型。
- 四格同一成年人物、服装、配饰、体型、画风和一致的光照/明暗体系。
- 已批准原设逐项对照；没有身份参考或被遮挡的细节只能标无法判断。

版式或身份失败不能以画面漂亮替代通过。只修改失败项，保留已通过项；未经用户批准不升级正式资产。
